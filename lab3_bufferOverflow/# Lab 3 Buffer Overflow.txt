# Lab 3: Buffer Overflow

## Objective:
The purpose of this lab is to understand how a buffer overflow occurs. It occurs when a program writes more data into a fixed-size buffer than it can hold. Students will compare secure and vulnerable input handling methods and observe how improper bounds checking can corrupt adjacent memory such as a canary value and return address.
