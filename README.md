# VM
#### The goal of this project is to create labs that will be used on a virtual machine that will be used by students to teach them more about some aspects of secure software principles. This was made for a project in secure software engineering.
--- 
## Virtual Machine Environment Setup and Tools

Virtual machines are typically started with software. We will use VirtualBox, a general-purpose virtual machine, because of its ease of use compared to other software. It also runs on x86_64 hardware, meaning most computers, even ones over a decade old, can run it. We are using the Windows version, but it can also run on macOS and Linux.

Specifically, we want to use VirtualBox Extension Pack as it adds more features like the ability to run usb and use of webcams. These features are not needed for our modules currently, but could be used if new modules or the current ones are updated. 

Going to the following website, https://www.virtualbox.org/wiki/Downloads, you can download the extension pack, and go through the installation process. 

We will also need to download an iso file. An iso file acts like a disk that virtually downloads an operating system on the virtual machine. We will use Ubuntu, and the link to it is https://ubuntu.com/download/desktop. Ubuntu is the most popular Linux operating system. 

Now you can follow this guide to install and start the virtual machine: https://www.virtualbox.org/manual/topics/create-vm.html. 

There are individual instructions for each lab, but everything is based on Virtualbox and Ubuntu.
